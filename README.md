# A Gentle Interactive Space 🤎

This project is a multi-page, interactive frontend website designed as a calm, supportive digital space.  
It focuses on emotional reassurance, presence, and gentle interaction rather than productivity or performance.

The site is intentionally minimal, quiet, and responsive — allowing the user to move at their own pace and feel acknowledged without pressure.

---

## 🌿 Purpose

The goal of this project is to explore how thoughtful interaction design and simple frontend technologies can be used to create emotionally aware experiences.

Instead of telling users how to feel, the site:
- Listens to user choices
- Adapts its responses
- Offers reassurance without demanding change
- Creates a sense of safety and presence

---

## ✨ Features

- **Multi-page emotional flow**  
  Each page focuses on a single emotional intention to avoid overwhelm.

- **Mood-based navigation**  
  User choices guide the experience and determine what content appears next.

- **Memory-aware responses**  
  The site remembers the user’s selected mood locally using `localStorage`.

- **Click-to-reveal interactions**  
  Content unfolds only when the user is ready.

- **“Today is hard” adaptive mode**  
  A soft, responsive state that provides immediate comfort without interruption.

- **Subtle animations & feedback**  
  Gentle transitions and visual responses to create a calm experience.

- **Decorative SVG assets**  
  Lightweight vector graphics used sparingly for warmth and intimacy.

- **Fully responsive**  
  Designed to work smoothly on both desktop and mobile devices.

---

## 🛠 Tech Stack

- **HTML5** – Semantic, accessible structure  
- **CSS3** – Custom styling, transitions, and animations  
- **JavaScript (Vanilla)** – Interactivity, navigation logic, and local memory  

No backend, no frameworks, and no external libraries are used.

---

## 🔒 Privacy & Simplicity

- No user data is collected or transmitted
- All state is stored locally in the browser
- No analytics, tracking, or cookies
- Fast loading and offline-friendly once cached

## ▶️ Running the Project Locally

You can run this project without any setup:

1. Open the folder in **VS Code**
2. Install the **Live Server** extension
3. Right-click `index.html` → **Open with Live Server**

Alternatively, double-click `index.html` to open it directly in a browser.

## 💡 Design Philosophy

- Slow pacing over instant feedback  
- Presence over persuasion  
- Choice over instruction  
- Soft visuals over high contrast  
- Calm over stimulation  

Every interaction is designed to respect emotional boundaries.
